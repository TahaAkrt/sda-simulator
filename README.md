# sda-simulator
# 🛰️ Uzay Alan Farkındalık Simülatörü

Bu proje, IEEE TAES 2025'te yayınlanan bilimsel makaleye dayalı 
interaktif bir web simülasyonudur.

## 📄 Makale
**"Enhancing Space Domain Awareness Using Star Trackers in Satellite Formations"**  
Thangavel, Burroni, Servidia, Spiller, Sabatini  
IEEE Transactions on Aerospace and Electronic Systems, Vol.61, No.3, Haziran 2025  
DOI: 10.1109/TAES.2025.3528922

## 👨‍💻 Geliştirici
**Taha Akkurt**

## 🔗 Canlı Demo
https://tahaakrt.github.io/sda-simulator

## ✨ İçerik
- Gerçek zamanlı parallaks tabanlı RSO konum belirleme
- Star Tracker & GNSS simülasyonu
- Monte Carlo hata analizi
- Gibbs yöntemi ile yörünge belirleme
- Hassasiyet analizi grafikleri

## 🚀 Kullanım
Tarayıcıda `index.html` dosyasını açın.  
Hiçbir kurulum veya bağımlılık gerekmez.
